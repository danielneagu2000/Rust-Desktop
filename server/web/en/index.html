How it works

Connected in under a minute.

  1. Order a license

    Choose a plan on shop.rdndata.ro and receive your license code by email.

  2. Install the app

    Download RDN Remote and enter the code when it first starts. On a Mac, allow “Screen Recording” and “Accessibility”.

  3. Connect

    Enter the device ID and the one-time password shown on it, or the permanent password you set.

  4. Work as if you were there

    Control the screen, move files and chat. When you finish, the one-time password expires.

Frequently asked questions

What to know about RDN Remote.

What is RDN Remote?

RDN Remote is remote desktop software that lets you connect to computers and phones from anywhere, for IT support, working from home or managing the computers in your company. Connections go through RDN Network Data servers in Romania, in the EU.

Is RDN Remote an alternative to TeamViewer or AnyDesk?

Yes. It offers full remote control, file transfer and unattended access, with the difference that your data goes through our own server in Romania (EU) rather than a third-party cloud, and support comes straight from the team that runs the server.

Is it secure?

Connections are end-to-end encrypted between the two devices. The server only puts them in touch and cannot see the screen, keystrokes or files. Repeated password-guessing attempts are blocked automatically.

Which systems does it run on?

Windows, macOS, Linux and Android. From an iPhone or iPad you can control other devices, but they cannot be controlled themselves because of a limitation set by Apple.

How do I activate the license?

After ordering you receive a license code. Install the app, enter the code when it first starts and you can begin right away. Every device you install the app on uses one seat of the license.

What is the organization portal?

It is a web page at remote.rdndata.ro/portal where your company's administrators see every device on the license, who is online and who is connected right now, the session history and the monthly reports. From there they also choose which devices may control other computers and which computers accept connections from outside the company, end a session, free up a license seat and add colleagues with admin or view-only rights. The portal is included in the Advanced plan.

Is there a speed limit?

We do not impose a speed limit: image quality depends on the devices' internet connection. On request, we can cap the bandwidth used by each customer.

How do I connect to a computer remotely?

Install RDN Remote on both devices. The computer you connect to shows an ID and a one-time password; enter them in your app and press Connect. On your own computers you can set a permanent password, so you can connect even when nobody is there.

Can I control my computer from my phone?

Yes. With the Android app you see the computer's screen and control it by touch, from anywhere with internet. For iPhone and iPad, the app is available on request.

What is unattended access?

It means connecting to a computer that nobody is sitting at, such as a server or your office PC. You set a permanent password on that computer and connect at any time with its ID.

Is RDN Remote free?

The app is free to download, but it works with a license: €10 per month for the Standard plan and €50 per month for Advanced, for 1, 3, 6, 9 or 12 months.
