Legătura cu shopul

Când o comandă ajunge în starea aleasă la „Reguli pentru comenzi” panoul creează licența, sau o prelungește pe cea pe care clientul o are deja pentru același produs (codul rămâne același), și trimite codul clientului ca notă la comandă, pe e-mail (după întârzierea aleasă). În WooCommerce → Setări → Avansat → Webhook-uri adaugă: subiect Comandă actualizată, URL de livrare , cheie secretă de mai jos.

Cheile REST API (WooCommerce → Setări → Avansat → REST API, permisiune Citire/Scriere) servesc doar la trimiterea notei cu codul. Fără ele, codurile apar mai jos și le trimiți tu.

Setări generale

Sesiunile noi folosesc imediat noile durate; cele deschise își păstrează expirarea.

Blocările după încercări greșite se setează în tab-ul IP-uri blocate, iar legătura cu shopul în tab-ul Shop. Parola și 2FA-ul acestui panou rămân în server/.env (pe server).

Raport pe client

Activitatea fiecărei licențe în luna aleasă. Pornite = sesiuni deschise de pe dispozitivele licenței (de tehnicienii clientului); primite = sesiuni în care un dispozitiv al licenței a fost controlat. Istoricul se păstrează 180 de zile.

Backup

Un backup conține cheia serverului, ID-urile înregistrate, licențele, istoricul, IP-urile blocate și setările (server/.env). Se face automat zilnic (se păstrează ultimele 14). Descarcă periodic un backup pe alt dispozitiv: cele de aici se pierd dacă se strică discul serverului. Fișierul conține cheia privată a serverului și parola panoului; păstrează-l în siguranță.

Restaurare

Din panou se restaurează licențele, istoricul, dispozitivele și IP-urile blocate, pe același server (aceeași cheie). Înainte, panoul face automat un backup al stării curente.

Restaurare completă (server nou, disc defect, cheie pierdută): copiază backup-ul pe server și rulează sudo ./server/restore.sh /cale/backup.tar.gz. Pe un calculator nou rulează întâi install.sh.
